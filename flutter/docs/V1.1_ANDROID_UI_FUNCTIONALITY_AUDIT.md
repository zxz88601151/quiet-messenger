## 3. CRITICAL — Production Code Defect

### DEFECT-UI-001: FriendNotifier 未在 DI 中注册

**严重程度**: CRITICAL (运行时崩溃)

**现象**: `FriendsPage`、`AddFriendPage`、`FriendRequestsPage` 三个页面均通过 `context.read<FriendNotifier>()` / `context.watch<FriendNotifier>()` 访问状态，但 `app.dart` 的 `MultiProvider` 中**没有注册 `FriendNotifier`**。

**证据**:
- `app.dart` providers 列表中无 `ChangeNotifierProvider<FriendNotifier>`
- `friend_notifier.dart` 定义了 `FriendNotifier extends ChangeNotifier`
- `friends_page.dart:28` → `context.read<FriendNotifier>().loadFriends()`
- `add_friend_page.dart:72` → `context.read<FriendNotifier>().search(q)`
- `friend_requests_page.dart:27` → `context.read<FriendNotifier>().loadRequests()`

**后果**: 用户点击底部导航"好友"时，Flutter 抛出 `ProviderNotFoundException: Could not find the correct Provider<FriendNotifier> above this FriendsPage Widget`，应用崩溃。

**为什么之前 GATE 未发现**: 此前 Android-B GATE 测试可能未导航到好友页面，或测试范围不包含好友功能。

**修复方向 (Repair Phase)**: 在 `app.dart` 中添加 `ChangeNotifierProvider<FriendNotifier>`，依赖 `FriendRepository`（ProxyProvider 模式）。
