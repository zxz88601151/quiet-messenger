## 1. Implementation Summary（实现摘要）

Phase 2B 在 Phase 2A 的 8 表骨架与 Alembic 迁移之上，完整实现认证契约（API_CONTRACT §1）：

- `app/core/security.py` — bcrypt 密码哈希/校验；Refresh Token（不透明随机串 + SHA-256 哈希落库）；Access Token（JWT，短效，含 `type` 声明）；token 吊销/校验。
- `app/schemas/auth.py` + `app/schemas/user.py` — 请求/响应 Schema，含空白裁剪、phone 数字校验、长度限制；响应剥离 `password_hash`/`password`。
- `app/core/errors.py` — 统一错误结构 `{"error":{ "code","message","status" }}`（契约 §7）。
- `app/core/deps.py` — `get_db()` + `get_current_user()`（Bearer 提取 + Access Token 解码）。
- `app/services/auth_service.py` — register / login / refresh（轮换）/ logout / forgot-password / reset-password；Device 绑定；Dev Mock 重置码（内存、生命周期 + 单次使用）。
- `app/routers/auth.py` — `/api/v1/auth/*` 6 端点。
- `app/main.py` — 追加 `RequestValidationError` 处理器（→ 400 VALIDATION_ERROR，契约 §7 第 86-90 行语义统一）+ HTTPException 扁平化处理器。

**关键设计决策（已对齐契约，未自行扩大）：**
- Refresh Token 为**不透明随机串**，仅哈希落库，非 JWT（修正了一处将 refresh token 误作 JWT 解码的实现缺陷）。
- 重置密码后**不强制全量失效**旧 refresh token（契约未定义 → 不自行扩大范围）。
- 登录失败 / 忘记密码对不存在账号**统一响应**，`INVALID_CREDENTIALS` / `ok=true`，杜绝用户枚举。
- 重复 logout（已吊销 token）→ 401，幂等安全。

## 3. JWT

- 算法：HS256（来自配置 `JWT_ALGORITHM`）。
- Access Token：`sub`=user_id，`type`="access"，`iat`，`exp`（`ACCESS_TOKEN_EXPIRE_MINUTES`，默认 30）。可选 `device_id`。
- Refresh Token：**不透明** `secrets.token_urlsafe(48)` 明文仅本次返回，库内仅存 SHA-256 哈希；可吊销、可轮换、有 `expires_at`（`REFRESH_TOKEN_EXPIRE_DAYS`，默认 30）。
- 校验：`decode_token` 校验 `type` 声明，防止 access/refresh 混用。
- Secret：仅从环境变量 `JWT_SECRET` 注入（见 §7 安全自检），不硬编码。

---

## 4. Password Security（密码安全）

- 哈希：bcrypt（`bcrypt.hashpw` + `gensalt`），哈希前缀 `$2`，**禁止明文/MD5/SHA\***。
- 校验：`bcrypt.checkpw`（恒定时间比较，防时序攻击）。
- 响应：User 公开结构**不含** `password` / `password_hash`（Schema `to_user_public` 已剥离）。
- 注册校验：username 3-32、phone 6-20 且纯数字、password 6-128、nickname 1-32；空白自动裁剪后判空。

---

## 5. Device Binding（设备绑定）

- 模型：User 1—N Device；`UNIQUE(user_id, device_identifier)`（Phase 2A 迁移已建）。
- 注册：无 device → 自动建默认 mobile 设备。
- 登录：有 `device_identifier` 且未吊销 → 复用；否则新建。
- 多设备：同用户不同 identifier 各自成设备（测试 `test_multi_device` 通过）。
- 同设备重登：复用同一 Device（测试 `test_same_device_relogin_no_duplicate` 通过）。
- 登出：置 `Device.revoked_at`（非删除，保留审计）。
