## 3. Database Tables（逐表，依据 DATA_MODEL）

| Table | PK | 关键字段 | Indexes | Unique 约束 |
|-------|----|----------|---------|-------------|
| users | id (UUID) | username, phone, password_hash, nickname, avatar, bio, **privacy_settings(JSON)**, created_at, updated_at | ix_users_username, ix_users_phone | username(单列), phone(单列) |
| devices | id (UUID) | user_id(FK), device_type(enum mobile/desktop), device_name, device_identifier, last_active_at, created_at, revoked_at | ix_devices_user_id | **(user_id, device_identifier)** |
| refresh_tokens | id (UUID) | user_id(FK), device_id(FK), token_hash, expires_at, revoked, created_at | ix_rt_user_id, ix_rt_device_id | token_hash(单列) |
| qr_login_sessions | id (UUID=session_id) | nonce, status(7态), device_id(FK?), user_id(FK?), expires_at, created_at, confirmed_at, authorized_at | ix_qr_device_id, ix_qr_user_id | nonce(单列) |
| friend_requests | id (UUID) | sender_id(FK), receiver_id(FK), status(pending/accepted/rejected), created_at, updated_at | ix_fr_sender, ix_fr_receiver | **(sender_id, receiver_id)** |
| friendships | id (UUID) | user_id(FK), friend_id(FK), created_at | ix_fs_user, ix_fs_friend | **(user_id, friend_id)** |
| conversations | id (UUID) | user_a(FK), user_b(FK), created_at, updated_at | ix_conv_a, ix_conv_b | **(user_a, user_b)** 规范化 min/max |
| messages | id (UUID) | conversation_id(FK), sender_id(FK), **client_message_id**(幂等), content, created_at, read_at | ix_msg_conv, ix_msg_sender | **(conversation_id, client_message_id)** |

**Message 服务端无 status 字段**（V1.1 冻结）。已验证。

**Device.sync_status / Now 状态**：均为客户端推导态 / 协议层值，**DB 不存储**（符合 DATA_MODEL）。

## 8. Issues

### 无阻断性问题（NO BLOCKING ISSUE）

轻微观察（不影响 PASS，已处理或记录）：
1. **autogenerate 不推导复合 UNIQUE**：初次生成迁移遗漏 5 个复合唯一约束。已通过在 Model 显式声明 `UniqueConstraint` 并重新 autogenerate 解决，Model↔Migration 保持单一事实源。
2. **迁移引用自定义类型**：生成的 migration 直接引用 `app.models.user.UUID()`，已在迁移顶部 `from app.models.user import UUID` 并替换引用，确保 upgrade 可独立执行。
3. **SQLite UNIQUE 以 unique index 实现**：`get_unique_constraints` 在 SQLite 返回空，测试已同时检查 unique index，断言稳健。
4. **Now 状态 DB 字段缺失**：符合 DATA_MODEL（Now 不落库），Test I 标记 NOT RUN 而非 FAIL，避免误报。
