## 19. Bugs Found

**本阶段未发现真实产品 Bug。**

测试过程中发现的 3 个问题均为**测试脚本问题**，非产品 Bug：
1. 好友请求字段名：测试脚本使用 `username`，正确字段为 `target_username_or_phone`
2. WebSocket 认证：测试脚本使用 URL query token，正确方式为 Header `Authorization: Bearer`
3. 事件字段名：测试脚本使用 `event_type`，正确字段为 `type`

以上 3 个问题修复后，全部 19 个测试通过。
