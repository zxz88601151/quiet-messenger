# V1.1 IM FEATURE PARITY AUDIT

**Date:** 2026-08-25
**Baseline:** WeChat / QQ (mature IM products)
**Project:** V1.1 双端聊天 / Minimal Chat
**Type:** READ-ONLY AUDIT (no code modifications)

---

## 1. Executive Summary

当前项目作为极简私人通讯工具，在**核心通讯能力**上已经达到可用状态：注册登录、好友、会话、消息收发、历史、离线同步（代码层面）、WebSocket 实时、Presence、多设备登录、安全审计均已实现。

与微信/QQ 成熟 IM 相比，当前项目在以下方面存在明确差距：
- **消息生命周期**：缺少 Delivered / Read 状态
- **消息操作**：缺少删除 / 撤回 / 转发 / 引用 / 回复 / 编辑 / 搜索
- **好友系统**：缺少拉黑 / 解除拉黑 / 好友备注 / 取消请求
- **会话管理**：缺少删除 / 归档 / 免打扰 / 置顶
- **通知**：缺少系统级 Push Notification（后台/杀进程后无法收到）
- **媒体**：图片/文件/语音/视频全部 BLOCKED（后端无存储）
- **未读同步**：未读数跨设备同步未验证

**核心结论：** V1.1 作为"人与人连接 + 安静可靠的私人通讯"工具，核心能力完整。上述差距多数属于 V1.2 / Future 范畴，或与极简定位冲突（如朋友圈/小程序明确 NOT PLANNED）。

## 4. Core IM Audit

### 4.1 Authentication / Account

**PASS** — 注册、登录、登出、Refresh、Token 持久化、401 处理、多设备登录全部实现。

**关键能力：**
