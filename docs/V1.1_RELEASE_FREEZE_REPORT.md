## 6. Recent Fixes Verification

### PRESENCE-RT-001: Initial Presence Sync Gap
- **修复：** `ws.py` 在 `connection.ready` 后发送初始 `presence.update`（`initial: true`）
- **状态：** ✅ 已部署 Staging，代码已同步本地

### PRESENCE-RT-002: UUID vs String Mismatch
- **修复：** `presence.py` `_get_friend_ids()` 返回 `[str(r) for r in rows]`
- **状态：** ✅ 已部署 Staging，代码已同步本地

### Offline Message Sync
- **修复：** `MessageNotifier` / `MessageController` 添加 `addStateListener`，disconnected→connected 时自动 `_reconcile()`
- **Reconcile 逻辑：** 保存 failed/sending → 加载最新 50 条 → 合并本地消息 → 按 id 去重 → 按 created_at 排序 → notifyListeners
- **守卫：** `_hasBeenConnected` + `_wasDisconnected` + `_reconciling` 防止首次连接触发和重复 reconcile
- **状态：** ✅ 代码验证通过，三端测试全绿
