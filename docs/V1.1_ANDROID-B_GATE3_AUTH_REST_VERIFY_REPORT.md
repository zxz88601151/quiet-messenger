## 13. 发现与偏差（OBSERVATION / DEVIATION）

### 🔴 P2 — CONTRACT DRIFT（契约漂移）
当前 Staging 后端契约 vs Staging E2E 报告严重不符：
1. register 现强制 `phone` + `nickname`（E2E 时无需）
2. login 用 `identifier`（非 `username`）
3. `/me` 路径现为 `/api/v1/users/me`（原 `/api/v1/auth/me` 已不存在→404）
4. DeviceInput.device_type 合法枚举 = `mobile`（android/ios/web 均 400）

**风险提示**：若 Android Client（api_config / AuthRepository）仍按旧 E2E 契约实现，真机 UI 登录将实际收到 400 失败。这是 GATE3 未闭合的 CLIENT 层核心风险点，需真机 UI 登录实测确认。

### 🟡 OBSERVABILITY / SECURITY — DB 密码暴露事件
DB 密码因含 `/` 与 `+` 特殊字符，在首次 psycopg URL 解析 traceback 中一度于执行 stderr 暴露明文片段。已立即改用参数式连接且不回显。
**建议**：GATE3 结束后轮换 `chat_staging_user` 数据库密码（凭据已在本次会话中暴露）。
