**结果：BLOCKED BY ENVIRONMENT（自签证书仅本地验证，已如实标注）**

- 无真实域名 → 无法向 CA 申请真实证书。

  - HTTP `:9088/health` → `301` 跳 `https://.../health` PASS
  - HTTPS `:9433/health` → `200`，body `phase:2D` PASS
  - HTTPS `:9433/api/v1/users/me` → `401`（鉴权守卫经 TLS 生效）PASS
  - HTTPS `:9433/api/v1/auth/register` 非法体 → `400 VALIDATION_ERROR` PASS
  - HTTPS `:9433/` → `404`（无前端）PASS
- 真实生产证书（Let's Encrypt / 商业 CA）需在中哥提供域名后由 `certbot` 签发，挂载到 `deploy/nginx/certs/fullchain.pem`。此为部署上线前置条件，**非代码缺陷**。
