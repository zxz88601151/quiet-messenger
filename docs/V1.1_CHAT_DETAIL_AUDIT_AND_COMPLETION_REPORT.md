## 4. Implemented Changes

### 4.1 Android — `flutter/lib/features/chat/pages/chat_page.dart`

**完整重写**，实现以下 P0 功能：

#### 4.1.1 Header (`_ChatHeader`)
- **Avatar**: `CircleAvatar` 显示 `peer.avatar`（NetworkImage），无头像时显示首字母
- **Nickname**: 优先 `peer.nickname`，fallback `peer.username`
- **Online indicator**: 接入 `PresenceNotifier.isOnline(peer.id)`，绿色圆点=在线，灰色=离线
- **More menu**: `PopupMenuButton` 含"查看资料"（可用）和"拉黑（暂不可用）"（disabled）
- **Avatar tap**: 点击头像/昵称区域 → 导航到好友资料页（当前 SnackBar 占位，待 FriendProfilePage 实现）

#### 4.1.2 Date Grouping (`_DateSeparator`)
- 按消息 `createdAt` 日期分组
- "今天" / "昨天" / "MM月dd日" / "yyyy年MM月dd日"（跨年）
- 居中胶囊样式，低视觉噪音

#### 4.1.3 Message Timestamp
- 每条消息下方显示 `HH:mm`
- 自己消息同时显示发送状态（"发送中…" / "失败·点击重试"）

#### 4.1.4 Empty State (`_EmptyChatState`)
- 居中图标 `chat_bubble_outline`
- "你们已经是好友" + "开始聊天吧"
- 低饱和度设计

#### 4.1.5 Bubble Refinement (`_Bubble`)
- `SelectableText` 支持长按选择/复制
- `maxWidth 72%` 防止横向溢出
- `height: 1.35` 多行文本行距
- 圆角 14px，自己=主色白字，对方=背景色+边框
- 长文本/emoji/中英文混排均正常显示

#### 4.1.6 Long Press Menu
- `GestureDetector.onLongPress` → `showModalBottomSheet`
- **复制**: `Clipboard.setData` + SnackBar "已复制"
- **删除**: disabled 项，标注"暂不可用"（后端无 DELETE API → BLOCKED）

#### 4.1.7 New Message Indicator (`_NewMessageButton`)
- `ScrollController` 监听滚动位置
- 用户不在底部时收到新消息 → 计数累加
- 显示浮动按钮 "↓ N 条新消息"
- 点击 → 平滑滚动到底部 + 计数清零

#### 4.1.8 Scroll Behavior
- 在底部时收到新消息 → 自动平滑滚动到底部
- 阅读历史时收到新消息 → 不抢滚动位置，仅显示计数
- 自己发送消息 → 滚动到底部
- `_isAtBottom` 标志精确判断（阈值 24px）

#### 4.1.9 Reconnect Banner (`_ReconnectBanner` / `_ConnectedFlash`)
- 订阅 `RealtimeClient.addStateListener`
- `reconnecting` → 橙色横幅 "正在重新连接…" + 旋转指示器
- `disconnected` → 红色横幅 "连接已断开"
- `connected`（从断开恢复）→ 绿色 "已连接" 闪烁 2 秒后自动消失
- 无永久状态 UI

#### 4.1.10 Composer (`_Composer`)
- `[+]` 按钮：媒体入口占位，点击提示"图片/文件功能暂未开放"（后端无媒体存储 → BLOCKED）
- `TextField`：minLines=1, maxLines=4, send 键发送
- 发送按钮：有文本时主色，无文本时灰色 disabled
- 发送后清空 + 滚动到底部

#### 4.1.11 Architecture
- `_ChatBody` (StatefulWidget): 管理 ScrollController / 新消息计数 / 连接状态订阅
- `_ChatScaffold` (StatelessWidget): 分离 MessageNotifier consumer 与滚动状态
- `ChangeNotifierProvider<MessageNotifier>`: 复用现有 MessageNotifier，未修改
- 所有 Realtime/Auth/Friend 集成保持不变

### 4.2 Desktop — `desktop/app/features/chat/chat_page.py`

## 9. Known Limitations

1. **Android 头像点击**: 当前为 SnackBar 占位，未导航到真实好友资料页（ProfilePage 存在但是当前用户的，非好友资料页）
2. **Desktop 功能深度**: Desktop 仅完成最小 UI 补齐（header/气泡/时间/空状态），未实现新消息指示器、重连横幅、长按菜单、滚动行为精细化
3. **消息分页**: Android `MessageNotifier` 有 `hasMore` 标志但无 `loadMore` 实现，当前仅加载最近 50 条
4. **消息删除**: 后端无 API，长按菜单中删除项为 disabled
5. **媒体功能**: 后端无存储，+ 按钮为占位提示
6. **真机验证**: APK 已构建但设备未连接，未进行真机 Runtime 验证
