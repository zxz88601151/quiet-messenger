## 7. API Client 基础（API Client Foundation）

双端均实现**基础设施**（不写业务流）：

- **Base URL 配置**：`ApiConfig` 支持 `development`(localhost:8000) / `staging`(192.168.3.200:9080，路由 `/api/v1`)，**不硬编码 Production**。
- **HTTP 方法**：GET / POST / PATCH / DELETE。
- **Authorization Header**：请求拦截器自动注入 `Bearer <access_token>`（来自 TokenStorage）。
- **统一错误解析**：映射后端 `{error:{code,message,status}}`（API_CONTRACT §7）→ 类型化 `ApiException`（Flutter）/ `ApiException`（PySide6）。
- **Token 存储**：`flutter_secure_storage` / `keyring`（内存降级）；含 Access + Refresh stub。
- **Repository Stub**：Auth / Conversation / Friend / Device / User 各抽象类 + Stub 实现（方法体空，仅标注 3D/3E 落点）。
