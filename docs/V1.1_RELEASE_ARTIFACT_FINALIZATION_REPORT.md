## 4. Desktop Release Packaging

### PyInstaller 安装

| 项目 | 值 |
|------|-----|
| PyInstaller 版本 | 6.22.2 |
| 依赖 | altgraph 0.17.5, pefile 2024.8.26, pyinstaller-hooks-contrib 2026.7, setuptools 84.0.0 |

### 打包命令

```bash
pyinstaller --onefile --windowed --name "QuietMessenger" \
  --add-data "app/assets/sounds;app/assets/sounds" \
  --collect-submodules PySide6 \
  app/main.py
```

### 打包参数说明

| 参数 | 作用 |
|------|------|
| `--onefile` | 打包为单个 exe 文件 |
| `--windowed` | 无控制台窗口（GUI 应用） |
| `--name "QuietMessenger"` | 输出文件名 |
| `--add-data` | 包含音效资源文件（friend_added.mp3, new_message.mp3, online.mp3） |
| `--collect-submodules PySide6` | 收集所有 PySide6 子模块，避免运行时 ImportError |

### 打包结果

| 项目 | 结果 |
|------|------|
| 输出文件 | `desktop/dist/QuietMessenger.exe` |
| EXE 大小 | 67.7 MB |
| 构建时间 | ~170s |
| 启动验证 | ✅ PID 13324，运行 5 秒无崩溃，手动停止 |
| 音效资源 | ✅ 已打包（3 个 mp3 文件） |

### 已知限制

1. **无自定义应用图标** — 使用 PyInstaller 默认图标
2. **无版本信息** — EXE 文件属性中无版本号/公司名/产品名
3. **无安装程序** — 单文件 exe，非 Setup.exe（用户可直接运行）
