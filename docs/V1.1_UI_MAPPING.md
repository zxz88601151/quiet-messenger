# V1.1 UI Prototype → Dual-Client Mapping

> 来源原型：`index.html`（V1.1 UI Prototype，1497 行，含 Design System + Mobile M01–M14 + Desktop D1–D7）
> 单一事实源优先级：Contract > State Machine > Scope > HTML Prototype
> 若原型与 Contract 冲突：以 Contract 为准（不修改 Backend Contract 以匹配原型）
> 本文档建立 **页面 / 组件 / 交互** 的映射基础，不是像素级复刻，也不是生产代码。

---

## 一、Design System（原型 Design System 区块）

| 原型元素 | 映射目标 | 备注 |
| --- | --- | --- |
| Colors（`--primary:#2563EB` 等） | `flutter/lib/app/theme/colors.dart` + `desktop/app/theme/colors.py` | 语义化命名，为 Dark Mode 预留 |
| Typography（13/12/11px 等） | `app/theme/typography.dart` + `typography.py` | 单字体栈，4 级层级 |
| Spacing / Radius（`--r-*`） | `app/theme/spacing.dart` + `typography.py` | 6/8/12/16 + full |
| Shadows（`--sh-sm/md/lg`） | `app/theme/spacing.dart` AppShadows | 映射到 BoxShadow |
| Buttons / Inputs / Avatar / Status / Bubble | `desktop/app/widgets/common.py` + Flutter 原生 Widget | 统一组件基元 |

**主色冲突说明**：原型用 `#2563EB`；早期记忆提到 `#2D7FF9`。**以 HTML 原型为准 → `#2563EB`**。

## 五、交互映射原则

1. **原生实现**：Flutter 原生 Widget / PySide6 原生 Qt，禁止 iframe / WebView / 直接套用 index.html。
2. **布局/层级/间距/视觉语言继承原型**，交互逻辑以 Contract 为准。
3. **Chat 用本地 Mock State**（§13）：不接 WS，`message.created/read/typing/device.revoked` 属后续 Phase。
4. **禁止为原型按钮自行实现业务**：M13/M14/D1–D3 仅视觉占位。
5. **隐私/设备/Now 状态**严格按 V1.1_SCOPE：online/dnd/offline，无 busy/focus/away；消息状态客户端本地态。
