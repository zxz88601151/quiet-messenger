## 20. Release Notes (V1.1.0)

### Overview
Quiet Messenger V1.1 — 极简私人通讯的第一个正式版本。实现了完整的端到端通信闭环，支持 Android + Desktop 双端。

### Core Features
- **Authentication**: 注册/登录/Token/Refresh/Session 持久化/Logout
- **Friends**: 用户搜索/好友请求/接受/拒绝/好友列表
- **Chat**: 单聊/消息发送/历史/分页/幂等/失败重试/复制
- **Realtime**: WebSocket 实时消息/Presence/重连/去重/REST 恢复
- **Multi-device**: Android + Desktop 同时登录，设备管理
- **Privacy**: bcrypt 密码哈希/JWT 认证/安全存储/权限校验

### Android
- Header (Avatar/Nickname/Presence)
- 日期分组/消息时间/空状态
- 消息气泡/长文本/Emoji/复制
- 新消息指示器/智能滚动
- 重连状态提示/失败重试
- 个人资料/设备管理/设置

### Desktop
- 会话选择/Chat Header/自己对方消息区分
- 日期分组/时间戳/空状态
- 发送/失败/重试/实时消息
- Profile 页面/Devices 真实化/Settings 功能化
- Logout 确认/WebSocket 关闭

### Known Limitations
1. Desktop Chat 历史消息默认最近 50 条
2. Device revoke 无即时 WebSocket 通知
3. Desktop 未打包最终 Setup.exe
4. 当前 APK 为 Staging Release Candidate
5. 已读回执/输入中/媒体/Push/群聊属于 V1.2+

### Future Roadmap (V1.2+)
- 消息撤回/删除/搜索
- 拉黑/好友备注/二维码
- 已读回执/输入中提示
- 图片/文件/语音/视频
- Push Notification
- 群聊/音视频通话
- Global Message / System Announcement (Phase 4A)
