# V1.1 Scope Freeze — 双端聊天软件

> 本文档冻结 V1.1 的产品范围。所有开发必须严格遵循此范围，不得擅自扩大或缩小。
> 产品定位：极简私人通讯 / 极简社交。核心哲学：安静、可靠、属于自己。
> 原则：Less UI, More Connection.

---

## MUST HAVE（V1.1 必须实现）

以下 7 项是 V1.1 的核心交付，缺一不可。

### 1. Message Status（消息状态）
- 客户端展示状态：sending → sent → read，以及 sending → failed → sending（手动重发）
- 离线发送：waiting_network（客户端本地临时态，不持久化，手动重发）
- 服务端不新增 Message.status 字段，sending/failed/waiting_network 均为客户端本地态
- client_message_id 继续承担幂等与防重复发送职责

### 2. Network Status（网络状态）
- 顶部网络状态条：在线 / 网络不稳定 / 离线 / 重新连接中 / 已恢复
- 网络恢复后，如有 waiting_network 消息，顶部提示「有 N 条消息待发送 · 重发」，由用户手动触发
- 不自动发送离线消息

### 3. Privacy Core Settings（隐私核心设置）
- User.privacy_settings 包含 5 个键：
  - read_receipt_enabled（默认 true，严格对等原则）
  - online_status_visibility（默认 "all"，仅 all/none 两档）
  - typing_indicator_enabled（默认 true，严格对等原则）
  - new_device_login_alert（默认 true，唯一设置源）
  - message_retention（默认 "forever"，仅 forever/30_days/1_year 三档）
- 通过 PATCH /users/me 合并更新（merge patch），字段白名单校验

### 4. Devices Enhancement（设备能力增强）
- Devices 页面展示：设备类型、设备名称、在线/离线状态、同步状态（synced/syncing/pending）、最后活跃时间、移除设备
- sync_status 为客户端推导态，服务端不存储
- online ≠ synced，设备在线但正在同步是合法状态
- 新设备登录提醒真实开关放在 Devices → Security

### 5. Remove "People You May Know"（移除可能认识的人）
- 删除「可能认识的人」陌生人推荐逻辑
- 添加好友方式：手机号 / 用户 ID（扫码加好友进入 V1.2，见 POSTPONE #2）
- 禁止出现陌生人推荐、好友推荐、社交发现等功能

### 6. Remove Desktop Phone/Video Misleading Buttons（移除桌面端误导性按钮）
- Desktop Chat 页面当前存在电话 / 视频按钮，但 V1 不支持
- V1.1 必须删除这些按钮，或明确标注 Coming Soon（默认删除）
- 不得让用户看到当前不存在的功能入口

### 7. Login/Register Legal Links（登录注册法律链接）
- 登录 / 注册页面增加用户协议和隐私政策链接
- 保持视觉克制，不喧宾夺主
- 链接可点击，指向对应文档页面

## SHOULD HAVE（V1.1 建议实现，时间允许时完成）

以下 6 项提升产品品质，但不阻塞 V1.1 发布。

### 1. Typing Indicator（正在输入指示器）
- WS 事件：typing.start / typing.stop
- 不得按每次按键发送，start 后 1500ms 无输入发 stop
- 服务端按双方 typing_indicator_enabled 对等转发
- 对端 UI 轻量展示「XXX 正在输入…」，不抢占聊天内容

### 2. New Device Login Alert UI（新设备登录提醒 UI）
- 新设备登录时，通过应用内消息和系统通知提醒用户
- 提醒内容：设备名称、设备类型、登录时间、登录地点（如有）
- 用户可在 Devices → Security 中开关此提醒

### 3. Desktop Shortcuts（桌面端快捷键）
- 固定默认行为，不提供开关或自定义
- Enter = 发送，Shift + Enter = 换行
- Ctrl/Cmd + F = 搜索
- Esc = 返回 / 关闭当前浮层或页面
- Ctrl/Cmd + 1/2/3 = 导航（根据实际 V1 导航结构定义）
- 快捷键说明放在 About Chat 页面底部，可使用折叠区域

### 4. Minimal Now Status（极简 Now 状态）
- 手动状态：online（默认）、dnd（勿扰）
- 系统状态：offline（自动判断，用户不可手动设置）
- 删除 busy / focus / away（手动设置）
- dnd：正常接收消息，但不产生声音/振动/普通通知
- Now 状态不向好友广播为独立事件

### 5. Profile Device Status Shortcut（个人页设备状态快捷入口）
- Profile / Settings 页面增加设备状态快捷入口
- 展示当前在线设备数量，点击进入 Devices 页面
- 不增加一级导航

### 6. Desktop Device Status Indicator（桌面端设备状态指示器）
- Desktop 窗口边缘或状态栏展示当前设备的在线/同步状态
- 轻量展示，不干扰主界面
- 点击可进入 Devices 页面

## POSTPONE（V1.1 明确延期，不进入本轮开发）

以下 13 项属于未来版本，V1.1 不得实现。如发现现有文档或代码中存在这些功能，必须移除或标注为未来规划。

### 1. Full Offline Queue（完整离线消息队列）
- 自动重试、持久化队列（IndexedDB/SQLite）、页面刷新恢复、后台自动发送、指数退避
- V1.1 仅实现 waiting_network 临时态 + 手动重发
- 完整队列进入 V1.5

### 2. QR Add Friend（扫码添加好友）
- V1.1 添加好友方式：手机号 / 用户 ID
- 扫码添加好友进入 V1.2

### 3. Shortcut Settings Page（独立快捷键设置页）
- V1.1 快捷键固定为默认行为，不提供开关或自定义
- 不增加独立快捷键设置页面

### 4. Last Active / Last Seen（最后活跃时间）
- 好友之间仅展示 online / offline，不展示最后活跃时间
- 禁止显示「5 分钟前在线」「15 分钟前在线」「今天在线」等
- Devices 页面可展示用户自己设备的 last_active_at（设备安全信息，不属于好友在线状态）

### 5. Five-State Now（五状态 Now 系统）
- V1.1 仅保留 online / dnd（手动）+ offline（系统）
- 删除 busy / focus / away（手动设置）

### 6. Dark Mode（深色模式）
- V1.1 可延期
- Design System 必须使用语义变量（surface/text/border/accent/danger/warning/success），为未来主题切换预留基础
- 本阶段不要求真正实现 Dark Mode

### 7. Per-contact Online Visibility（按联系人在线状态可见性）
- V1.1 online_status_visibility 仅支持 all / none 两档
- 不支持 per-contact whitelist / blacklist / custom audience

### 8. Remote Message Deletion（远程消息删除）
- V1.1 不实现远程删除
- 「清除本地消息」仅删除本设备本地副本，不删除云端消息，不通知其他设备删除，不广播 remote delete event

### 9. Screenshot Notification（截屏通知）
- V1.1 不实现截屏检测和通知
- 进入 V1.5 评估

### 10. Handoff（跨端接力）
- 「在哪里停下，就在哪里继续」
- 阅读位置同步、草稿同步、内容接力、链接接力、图片/文件接力
- V1.1 仅为 Handoff 预留合理的产品和架构空间，不实现具体功能
- 进入 V1.5

### 11. Space（两人共享空间）
- 「我和某个人之间的小空间」
- 不是朋友圈、社区、群聊、信息流
- 可承载图片、链接、小提醒、简单待办、共享内容、共同记录
- V1.1 不实现，进入 V2.0

### 12. E2EE（端到端加密）
- V1.1 不实现端到端加密
- Privacy settings ≠ E2EE
- 不得设计任何明显阻碍未来 E2EE 的数据结构
- 未来 E2EE 架构需求记录在 Future Architecture Notes
- 进入 V1.5 架构评审后决定

### 13. Complex Message Actions（复杂消息操作）
- 撤回、编辑、删除、引用、@、回复、反应（emoji reaction）、转发
- V1.1 不实现以上任何复杂消息操作
- V1.1 仅支持：发送文本消息、消息状态展示、已读回执

---

## V1.1 明确禁止的功能（Anti-Features）

以下功能在 V1.1 及可预见的未来均不实现，因为它们违反「极简私人通讯」产品定位：

- 群聊
- 朋友圈 / 动态 / Feed
- 社区 / 论坛
- 陌生人推荐 / 可能认识的人 / 社交发现
- 短视频 / 内容消费
- 商城 / 支付 / 小程序
- AI 聊天机器人 / AI 首页 / AI 推荐 / AI 社交
- 游戏化 / 积分 / 排行榜 / 等级
- 广告 / 商业化入口
- 电话 / 视频通话（V1.1 删除误导性按钮）
- 公开动态 / 热榜 / 推荐内容

## Scope 变更流程

如需变更 V1.1 Scope（新增、删除、延期某项功能），必须：

1. 提交书面变更请求，说明变更原因和影响
2. 评估对产品定位、架构、开发周期的影响
3. 经产品负责人批准后，更新本文档
4. 同步更新 DATA_MODEL.md / WS_PROTOCOL.md / STATE_MACHINES.md / API_CONTRACT.md

未经批准，任何开发者不得擅自扩大 V1.1 范围。
